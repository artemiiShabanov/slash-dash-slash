# slash-dash-slash

Мобильный роглайк-слэшер, где рывок — единственный глагол: меч, самоцветы и офис 1970-х, в котором
бухгалтерия скрывает настоящую магию.

Godot 4.4, рендерер `mobile`. Проект Godot лежит в `slash-dash-slash/`: открыть `slash-dash-slash/project.godot`
в редакторе, запуск F5.
